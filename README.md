## 买到手先做什么：换绑、改密、验号

拿到账号先做两件事，顺序不能反：先把绑定的手机号换成自己的，再改密码。多数教程只讲“拿到号先改密”，但账号如果绑着虚拟手机号，改完密码原号码收不到验证码，后续登录会直接卡住。

**登录 App Store 的步骤**

1. 打开 App Store，点右上角头像进个人中心。
2. 拉到最底端，点“退出登录”，先退出当前的国区 ID。
3. 屏幕滑到最上方，输入买来的账号和密码登录。
4. 商店会自动切到对应区域，搜目标应用下载。

**只登 App Store，不要登 iCloud**

在“设置”顶部直接登录，登进去的是 iCloud。成品号一旦进 iCloud，设备可能被激活锁锁死，需要原账号密码才能解锁。你改过密码，卖家也帮不上忙。确实要登 iCloud，登录后立刻关掉“查找我的 iPhone”。

**改密顺序**

1. 浏览器打开 `appleid.apple.com`，用买来的账号登录。
2. 进“安全”板块，先把自己的手机号添加为受信任号码。
3. 验证通过后，再修改密码。
4. 同步更新密保问题和答案。

**下载完切回自己的 ID**

用成品号下载完应用，切回主 ID 再打开使用。长期挂在别人账号上，后续内购、云存档都容易出问题。

**到手建议检查的 7 项**

这不是账号星球的官方政策，是公开验号清单里比较实用的一套：

1. 能否登录 `appleid.apple.com` 看到完整账户信息。
2. 能否修改密码，新密码是否生效。
3. 能否添加自己的双重认证手机号，并删掉原绑定号码。
4. 登录设备列表里有没有陌生设备，有就全部移除。
5. 购买记录里有没有异常消费或未授权订阅。
6. 能否修改账单地址和安全问题答案。
7. 开启“查找我的 iPhone”，确认设备控制权在自己手里。

任何一项失败，先别充礼品卡，找客服换号或者直接弃号。一个有隐患的号比没有还麻烦，后面充进去的余额和订阅都可能一起清零。

**日常保活**

海外账号长期不活跃，苹果可能判定异常并停用。隔一段时间登一次 App Store，保持活跃度。一个设备上别同时挂太多外区 ID，频繁切换容易触发风控。

## 售后边界：3 天换货保什么，不保什么

3 天换货只保账号到手时本身有问题，不保苹果事后收回。

- 账号类商品：购买日起 3 天售后期，账密错误、无法登录这类质量问题免费更换。
- 邮箱类商品：购买日起 3 天内售后。
- 卡密类商品（礼品卡）：无售后期，有问题可随时联系客服处理。
- 充值类商品：到账后无法售后。
- 虚拟商品一经发货不支持退款，账密问题除外。

平台还明确写了几条：账号售出删档，买家自行保护账号安全，被盗无法找回；海外账号无法确定使用期限，建议保持活跃度、经常改密；如果苹果官方收回停用账号，平台不承担责任。

这几条合起来的意思是，3 天之后账号的安全基本靠你自己。第一时间改密、换绑手机号、不多人共用、不登 iCloud，做到这几条，出问题的概率会低很多。

**黑号怎么识别**

黑号是靠盗刷信用卡、撞库等非法手段拿到的账号，价格异常低，随时可能被原主人找回或被苹果封禁。判断方法不复杂：看价格是否低到离谱。美区 ID 只要两三块钱，大概率有问题。账号星球这类平台称账号是团队手工注册的，价格不是最低，卖点是合规和稳定。

**多人共用**

独享号理论上一个人用。一个号挂十几个设备，容易触发苹果风控，出现被锁、被挤下线。和朋友拼用要控制人数。
